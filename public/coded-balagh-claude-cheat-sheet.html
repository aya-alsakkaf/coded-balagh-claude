Part 2 · Six artifacts
Ask for a tool, not a paragraph
Name the artifact and the source in the first line.
Calculator
A cost or pricing calculator
Build an artifact: a cost calculator from the attached brief.
Inputs change the result.
Dashboard
Charts from a spreadsheet
Build an artifact: a dashboard from the attached file, with the row count and total.
Check one total first.
Chart and summary
One chart, three lines
Make one chart of donations by campaign and three summary lines.
One idea per chart.
Slide deck
Slides you can export
Make a 5-slide deck for the board from the attached report.
Exports to PowerPoint or PDF.
Document
A doc you edit and share
Write the volunteer guide as a doc.
Edit it in place.
Game or quiz
A small interactive tool
Build a 6-question quiz for new volunteers from the report.
Good for training.
Artifacts start private. You choose who sees them.

How you like answers, in every chat
Settings › Your Claude › Instructions

Project
One area of work: rules and files
Projects › New project
One campaign, one role.
Skill
One method, loaded when the task comes up
Use: + or /. Make: ask Claude, or upload a .zip (Plugins page › Add; older: Customize › Skills › +)
The description decides when it runs.
Who you are: memory. How you like it: instructions. One area: a Project. One method: a Skill.
