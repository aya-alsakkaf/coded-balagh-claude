Pre-flight (30 minutes before)

  • Presenting laptop: Claude desktop app updated, signed in to a paid account. The message box shows Cowork (or the new Claude experience).
  • Settings › Capabilities: Create and edit files is on (skills and artifacts need it). Web search is on (older layout; the new Claude experience has no toggle).
  • The day before: upload misbah-donor-thanks-skill.zip from the Plugins page, note the exact button labels for Task 3.2, then delete the skill again. If the new page refuses a skill .zip, teach the fallback: create the skill with Claude (Demo 3.2).
  • Run the Demo 1.2 calculator prompt once with the campaign brief and keep the real artifact open, to show next to the slide.
  • The CODED training Google account is connected to Gmail and Google Calendar, with the fictional inbox and Sunday 29 November's calendar loaded for Demo 2.1.
  • The Misbah Winter Campaign Project exists with the Task 3.1 instructions, the brand guide and the brief (the opener uses it). No donor-thank-you skill on the laptop: it is uploaded live on the find-skills slide. The receipts folder is unzipped on the desktop.
  • All 8 sample files are on the laptop and on a USB stick. Open this runbook, the backups and the answer key on your own screen.
  • Test the projector with the deck at full screen (F). Step through one player and press R to reset it. Check the calculator slide responds.

02Demo 1.1 · Claude · web searchIn the slide

Trained knowledge, then web search

No file needed.
▶Say“Without web search, Claude answers from what it learned. With it, Claude reads today's pages and shows you where the number came from.”
  1. Ask the first question: it tells Claude not to search. Note the rate and whether a date or a source is given.
  2. Ask again with the full prompt, which asks Claude to search the web. (Older layout: turn on Web search in the + menu first. The new Claude experience has no toggle.)
Prompts: paste in this order
Web search offDo not search the web. A US donor pledged USD 5,000 to our winter campaign. What is that in KWD?
Web search onSearch the web. A US donor pledged USD 5,000 to our winter campaign. What is that in KWD at today's rate? Use the Central Bank of Kuwait or another official source, and give me the link. One line: the rate, the date of the rate, and the KWD amount to three decimals.
What you should seeOff: an approximate rate from training, often with a note that it may be out of date, and no source. On: today's rate with its date, a link to the source, and the KWD amount calculated from that rate.
!If it failsShow the backup table. Rates change daily, so never put a rate on the slide as fact. The result is on the backup results page.
